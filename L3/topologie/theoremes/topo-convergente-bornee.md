# ⭐ Toute suite convergente est bornée

*Théorème* · Chapitre : [[01-espaces-metriques|1 – Espaces métriques, e.v.n.]] · Prop. 1.31 du cours (poly : Prop. 1.5) · [[topo-index-definitions|↩ Index]]

> [!IMPORTANT] Énoncé
> Toute suite convergente est bornée.

> [!SUCCESS]- Démonstration
> $x_n\to\ell$ : il existe $N$ avec $d(x_n,\ell)<1$ pour $n\ge N$. Avec $r=\max\{d(x_0,\ell),\dots,d(x_{N-1},\ell),1\}+1$ : $\forall n,\ x_n\in B(\ell,r)$.
