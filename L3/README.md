# 🎓 L3

Un dossier par matière. Dans chaque dossier :

```
L3/
└── nom-de-la-matiere/
    ├── README.md                ← fiche de la matière (modèle : modeles/matiere.md)
    ├── 01-premier-chapitre.md   ← un fichier par chapitre (modèle : modeles/chapitre.md)
    ├── 02-deuxieme-chapitre.md
    └── fichiers/                ← PDF, photos du tableau, exercices…
```

Numérote les chapitres (`01-`, `02-`…) pour qu'ils restent dans l'ordre.
