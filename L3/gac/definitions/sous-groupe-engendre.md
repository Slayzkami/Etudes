# 📘 Sous-groupe engendré par une partie

*Définition* · Chapitre : [[02-sous-groupes|II – Sous-groupes]] · § II.4 du cours · [[index-definitions|↩ Index]]

> [!NOTE] Définition
> Pour $A\subset G$, $\mathrm{Gr}\langle A\rangle$ (ou $\langle A\rangle$) est l'**intersection de tous les sous-groupes de $G$ contenant $A$**.

> [!IMPORTANT] Proposition
> $\langle A\rangle$ est un [[sous-groupe]] contenant $A$, et c'est le **plus petit** : tout sous-groupe contenant $A$ contient $\langle A\rangle$.
> Description : $\langle A\rangle$ = produits finis d'éléments de $A$ et de leurs inverses ; $\langle\emptyset\rangle=\{1\}$ ; $\langle x\rangle=\{x^n\mid n\in\mathbb Z\}$.

> [!EXAMPLE] Exemples
> - Dans $\mathbb Z$ : $\langle a,b\rangle=a\mathbb Z+b\mathbb Z=\operatorname{pgcd}(a,b)\,\mathbb Z$ (Bézout).
> - Dans $\mathbb C^*$ : $\langle 2\rangle=\{2^n\}$ infini ; $\langle i\rangle=\{1,i,-1,-i\}$.
> - $\langle\tau_1,\gamma\rangle=\mathfrak S_3$.
> - Si $H_1\lhd G$ : $\langle H_1\cup H_2\rangle=H_1H_2$ (TD1 ex. 10).
