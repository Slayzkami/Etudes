# 🔍 Recherches

Un dossier par sujet. Dans chaque dossier :

```
recherches/
└── nom-du-sujet/
    ├── notes.md     ← la synthèse (modèle : modeles/sujet-recherche.md)
    ├── sources/     ← une fiche par source importante (modèle : modeles/fiche-source.md)
    └── fichiers/    ← PDF, images, captures…
```

Pour un petit sujet, un seul fichier `notes.md` suffit largement.
